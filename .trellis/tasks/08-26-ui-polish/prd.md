# PRD: 博客界面美化

## Goal

在现有 Astro 博客主题（astro 7 + Tailwind 4，无组件库）基础上做「精致极简」方向的界面美化：提升视觉质感与交互细节，不改变既有功能与信息架构。

## Background

当前界面为 MVP 极简版：max-w-3xl 居中布局、emoji 图标（🌙☀️🐾）、基础排版。用户选定方向 1「精致极简」——延续原 VitePress 主题的内容优先气质，重点在字体层级、间距节奏、克制动效与暗色模式对比度。

## Requirements

- R1 整体视觉升级
  - 字体层级优化：标题/正文字体栈（含中文字体优先级）、行高与字距
  - 颜色层次：微调 `--bg/--fg/--muted/--theme-color`，暗色模式提升对比度与层次感
- R2 首页列表美化
  - 年份标题样式（弱化、装饰性）
  - 文章条目 hover 反馈（颜色/位移过渡），日期排版优化
- R3 文章页阅读体验
  - 标题装饰（如主题色点缀）
  - 引用块、代码块、表格观感增强；代码块圆角/内边距统一
  - 阅读进度条（文章页顶部，纯 CSS+少量 JS）
- R4 组件细节
  - 导航栏观感（边框弱化、间距）
  - 主题切换按钮 hover 动效；BackToTop 过渡更顺滑
  - 404 页美化

## Out of Scope

- 不引入组件库或图标库依赖（emoji 可保留或换内联 SVG，不新增 npm 依赖）
- 不新增页面与功能（归档页、关于页、RSS 等另立任务）
- 不改动内容集合 schema 与路由结构

## Acceptance Criteria

- AC1 `npx astro check` 0 error/warning；`npm run build` 成功无警告
- AC2 明暗两种模式下首页、文章页、404 页观感协调，暗色下文字对比度不低于 WCAG AA（正文 ≥4.5:1）
- AC3 首页条目有平滑 hover 过渡；无布局抖动
- AC4 文章页显示阅读进度条，随滚动平滑更新
- AC5 功能行为不变：列表过滤 public、年份分组倒序、主题切换持久化、返回顶部均正常

## Key Decisions

- D1 风格方向 = 精致极简（用户决策，2025-08-26）；不做卡片化
- D2 全部用 Tailwind 工具类 + global.css 变量实现，零新增依赖
